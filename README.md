# Portfolio Website

Modular portfolio website built with PHP and Tailwind CSS v4.

## Project Structure

```
s-portfolio/
├── assets/
│   ├── icons/
│   ├── images/
│   └── js/
│       └── main.js
├── components/
│   └── header.php      # Reusable header component
├── header.php          # Root wrapper for components/header.php
├── style/
│   ├── input.css       # Tailwind CSS v4 input
│   └── output.css      # Compiled stylesheet
├── index.php           # Main entry point
└── package.json
```

## Commands

- **Watch styles:** `npm run watch`
- **Build styles:** `npm run build`
- **Start PHP server:** `npm run serve`
